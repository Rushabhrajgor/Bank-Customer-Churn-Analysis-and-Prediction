# Bank-Customer-Churn-Analysis-and-Prediction

Project Title:
Bank Customer Churn Analysis & Prediction

Short Discription:
Built a machine learning-powered Bank Customer Churn Prediction System using Python to identify customers who are likely to leave the bank.
Developed an end-to-end workflow covering data preprocessing, feature engineering, model training, and prediction.
Implemented Logistic Regression, Random Forest, and XGBoost to build and optimize predictive models.
Integrated GridSearchCV for hyperparameter tuning and improved model performance through systematic evaluation.
Leveraged Python libraries such as Pandas, NumPy, Scikit-learn, XGBoost, Matplotlib, and Seaborn throughout development.
Focused on building a practical, data-driven solution that helps banks identify potential customer churn and make smarter customer retention decisions.

Tools and technologies:
Python
Pandas, NumPy
Matplotlib, Seaborn
SciPy
Scikit-learn, Feature-engine
Logistic Regression, Random Forest, XGBoost
GridSearchCV
Accuracy, Precision, Recall, F1-score
Joblib

Key features:
Exploratory Data Analysis (EDA): Univariate, bivariate and multivariate analysis of customer demographics and banking behaviour.
Data preprocessing: Outlier treatment using Winsorization, logarithmic transformations, categorical encoding and feature scaling.
Customer churn analysis: Investigation of age, geography, gender, account balance, tenure, complaints and customer engagement.
Predictive modelling: Implementation of Logistic Regression, Random Forest and XGBoost classifiers.
Hyperparameter optimization: GridSearchCV with five-fold cross-validation and F1-score optimization.
Model evaluation: Classification reports, confusion matrix and performance comparisons.
Model saving: Export of the selected model using Joblib.
